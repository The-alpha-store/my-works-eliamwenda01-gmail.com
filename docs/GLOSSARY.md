# Glossary: plain-language meanings

| Word | Meaning |
|---|---|
| **API key / anon key** | A text that identifies your app to a service. The Supabase *anon* key is public by design |
| **APK / AAB** | The installable app file / the upload format for Google Play |
| **Alias** | The name of a key inside a keystore |
| **Artifact** | A file produced by a GitHub build (for example the APK) |
| **Backend** | The server side: database, login, files |
| **Base64** | A way to turn a file into text so it can be stored as a secret |
| **Branch** | A separate line of work in Git; `main` is the official one |
| **CI/CD** | Robots that automatically build, test and release your code |
| **Commit** | A saved snapshot of your code in Git |
| **Compose** | Android's modern way to build screens in Kotlin code (no XML) |
| **Cron / pg_cron** | A timer that runs something on a schedule |
| **Edge Function** | A small program that runs on Supabase's servers |
| **FCM** | Firebase Cloud Messaging: Google's free push-notification delivery |
| **Gradle** | The tool that turns your code into an app |
| **JWT** | A signed login pass used by services |
| **Keystore (.jks)** | The locked file holding your app-signing key |
| **Migration** | One SQL file that changes the database; applied in order |
| **Policy (RLS)** | A database rule saying who may read or change which rows |
| **Pull request (PR)** | A proposed change that others (and robots) can review before it is merged |
| **Push token** | The address of one phone for push notifications |
| **Repository (repo)** | A project folder tracked by Git |
| **RLS** | Row Level Security: rules enforced inside the database |
| **Secret** | A value that must stay private: passwords, service-account keys, keystores |
| **Service role key** | A Supabase master key that skips all rules. Never put it in the app |
| **Sync (Gradle)** | Android Studio reading the build files and downloading libraries |
| **Tag** | A named label on a commit, such as `v0.3.0`, used to trigger releases |
| **Trigger** | A database function that runs automatically when data changes |
| **Webhook** | A web address that is called automatically when something happens |
| **Workflow** | A GitHub Actions recipe file in `.github/workflows/` |
